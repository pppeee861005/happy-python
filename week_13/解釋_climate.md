# 天氣資料解析程式碼詳解

這段程式碼的目的是 **從文本資料中提取和分析天氣信息**（降雨量、最高溫、最低溫），並按年份統計輸出。

---

## 1️⃣ 資料初始化

```python
lines = response.text.split('\n')
weather_data = defaultdict(lambda: {'tmax': [], 'tmin': [], 'rain': []})
```

| 函數/方法 | 說明 |
|---------|------|
| `split('\n')` | 將整個文本按換行符分割成單獨的行 |
| `defaultdict` | 特殊字典，初次訪問不存在的鍵時，自動創建預設值 |

**資料結構：**
```python
{
  年份: {
    'tmax': [溫度列表],
    'tmin': [溫度列表],
    'rain': [降雨量列表]
  }
}
```

**實例：**
```python
{2020: {'tmax': [28.5, 29.1], 'tmin': [15.2, 16.0], 'rain': [45.5, 50.2]}}
```

---

## 2️⃣ 資料篩選和解析

```python
parts = line.split()
if len(parts) >= 6 and parts[0].isdigit():
```

| 條件 | 說明 |
|------|------|
| `split()` | 自動忽略連續空格，將行分割成欄位列表 |
| `len(parts) >= 6` | 檢查至少有 6 個欄位（年、月、最高溫、最低溫、af、降雨量） |
| `parts[0].isdigit()` | 確認第一個欄位是數字（即年份），過濾掉標頭行 |

---

## 3️⃣ 資料清理

```python
tmax_str = parts[2].replace('*', '')
tmin_str = parts[3].replace('*', '')
rain_str = parts[5].replace('*', '')
```

- **`replace('*', '')`**：移除資料中可能存在的 `*` 號（表示數據有特殊符號）

**欄位索引對照：**

| 索引 | 內容 | 變數 |
|------|------|------|
| `parts[0]` | 年份 | - |
| `parts[2]` | 最高溫 | `tmax_str` |
| `parts[3]` | 最低溫 | `tmin_str` |
| `parts[5]` | 降雨量 | `rain_str` |

---

## 4️⃣ 缺失值檢查和資料轉換

```python
if tmax_str != '---':
    weather_data[year]['tmax'].append(float(tmax_str))
```

| 項目 | 說明 |
|------|------|
| `'---'` | 表示缺失值，需要跳過 |
| `float()` | 將字符串轉換為浮點數進行計算 |
| `append()` | 將有效資料添加到對應年份的列表中 |

---

## 5️⃣ 錯誤處理

```python
try:
    # 資料轉換邏輯
except ValueError:
    continue
```

- 捕捉無法轉換為數字的「髒資料」（例如文字、特殊符號）
- **`continue`**：跳過該行，繼續處理下一行

---

## 6️⃣ 統計計算與輸出

```python
if data['rain']:
    avg_rain = sum(data['rain']) / len(data['rain'])
    avg_rain_str = f"{avg_rain:.2f}"
else:
    avg_rain_str = "無資料"
```

| 部分 | 說明 |
|------|------|
| `if data['rain']` | 檢查該年是否有降雨量資料 |
| `sum() / len()` | 計算平均值 |
| `:.2f` | 格式化為 2 位小數 |

---

## 7️⃣ 溫度極值提取

```python
max_temp = max(data['tmax']) if data['tmax'] else "無資料"
min_temp = min(data['tmin']) if data['tmin'] else "無資料"
```

| 函數 | 說明 |
|------|------|
| `max()` / `min()` | 找出該年最高和最低溫 |
| 三元運算子 | 如果有數據則計算，否則顯示「無資料」 |

---

## 📊 輸出示例

```
年份    平均降雨量 (mm)  最高溫度 (°C)  最低溫度 (°C)
──────────────────────────────────────────────────
2020    120.45         32.5          8.2
2021    98.30          31.8          7.9
```

---

## 🎯 整體流程

1. **分割文本成行**
2. **逐行篩選有效資料**（排除標頭和格式不符的行）
3. **清理並驗證各欄位值**
4. **按年份分組存儲**
5. **計算每年的平均降雨量、最高溫和最低溫**
6. **格式化輸出結果表格**

# 三元運算子詳解

## 基本語法

```python
max_temp = max(data['tmax']) if data['tmax'] else "無資料"
```

這是 **Python 的條件表達式（三元運算子）**。

---

## 結構拆解

| 部分 | 說明 |
|------|------|
| `max_temp =` | 賦值給變數 `max_temp` |
| `max(data['tmax'])` | 如果條件為真，執行這個 |
| `if data['tmax']` | 判斷條件：檢查 `data['tmax']` 是否有資料 |
| `else "無資料"` | 如果條件為假，返回這個字符串 |

---

## 具體含義

```
如果 data['tmax'] 列表不為空
   → max_temp = 最高溫度的最大值

否則（列表為空）
   → max_temp = "無資料"
```

---

## 程式流程示例

### ✅ 情況 1：有溫度資料

```python
data['tmax'] = [28.5, 29.1, 27.8]

# data['tmax'] 不為空 → 條件為真
max_temp = max([28.5, 29.1, 27.8])  # 執行這行
# 結果：max_temp = 29.1
```

### ❌ 情況 2：沒有溫度資料

```python
data['tmax'] = []

# data['tmax'] 為空列表 → 條件為假
max_temp = "無資料"  # 執行這行
# 結果：max_temp = "無資料"
```

---

## 等效的 if-else 寫法

```python
# 上面的一行程式碼等同於：
if data['tmax']:
    max_temp = max(data['tmax'])
else:
    max_temp = "無資料"
```

💡 **三元運算子是更簡潔的寫法！**

# `split('\n')` 的結果

## 基本結構

形成一個 **列表（list）**，其中每個元素都是一行字符串。

---

## 具體例子

### 原始文本

```
2020 1 28.5 15.2 0 45.5
2020 2 29.1 16.0 0 50.2
2021 1 27.8 14.5 0 40.3
```

### 執行後的結果

```python
lines = response.text.split('\n')
# 結果為：
lines = [
    '2020 1 28.5 15.2 0 45.5',
    '2020 2 29.1 16.0 0 50.2',
    '2021 1 27.8 14.5 0 40.3'
]
```

---

## 視覺化說明

```
原文本（含換行符）
┌──────────────────────────────────────┐
│ 2020 1 28.5 15.2 0 45.5\n           │
│ 2020 2 29.1 16.0 0 50.2\n           │
│ 2021 1 27.8 14.5 0 40.3             │
└──────────────────────────────────────┘
              ↓ split('\n')
列表（list）
┌──────────────────────────────────────┐
│ [0] '2020 1 28.5 15.2 0 45.5'       │
│ [1] '2020 2 29.1 16.0 0 50.2'       │
│ [2] '2021 1 27.8 14.5 0 40.3'       │
└──────────────────────────────────────┘
```

---

## 數據結構特性

| 屬性 | 說明 |
|------|------|
| **類型** | `list`（列表） |
| **元素個數** | 文本中換行符的個數 + 1 |
| **每個元素** | 一行文本的字符串（不包含 `\n`） |
| **訪問方式** | `lines[0]`、`lines[1]`、`lines[2]`... |

---

## 程式碼驗證

```python
text = "2020 1 28.5 15.2 0 45.5\n2020 2 29.1 16.0 0 50.2\n2021 1 27.8 14.5 0 40.3"
lines = text.split('\n')

print(type(lines))        # <class 'list'>
print(len(lines))         # 3
print(lines[0])           # '2020 1 28.5 15.2 0 45.5'
print(lines[1])           # '2020 2 29.1 16.0 0 50.2'
```
