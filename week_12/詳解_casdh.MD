# 現金流輸入函數詳解

## 函式整體結構

這個函式的目的是 **互動式地收集某一類別的現金流項目和金額**，並以字典的形式返回。

```python
def input_cash_flows(category_name):
    """輸入現金流項目和金額"""
```

**函數特性：**
- 接收一個參數 `category_name`（類別名稱，如 "營運活動現金流"）
- 會被調用三次：營運、投資、融資各一次

---

## 逐行分析

### 1️⃣ 初始化存儲結構

```python
flows = {}
```

建立一個空字典，用來存儲 `{項目名: 金額}` 的對應關係。

---

### 2️⃣ 顯示類別標題

```python
print(f"\n請輸入【{category_name}】項目:")
```

向用戶顯示正在輸入哪一類別的現金流。

**例如會印出：** `請輸入【營運活動現金流】項目:`

---

### 3️⃣ 無限迴圈 - 持續收集項目

```python
while True:
    item = input(f"  輸入項目 (按 Enter 結束): ").strip()
```

| 部分 | 說明 |
|------|------|
| `while True:` | 持續運行，直到用戶決定結束 |
| `input(...)` | 提示用戶輸入項目名稱 |
| `.strip()` | 移除項目名稱前後的空白字元（空格、制表符等） |

---

### 4️⃣ 結束條件 - 檢測空輸入

```python
if not item:
    break
```

| 條件 | 說明 |
|------|------|
| `item` 為空字符串 | 用戶按 Enter 鍵而不輸入任何文字 |
| `if not item:` | 檢測到空字符串 |
| `break` | 跳出迴圈 |

**這是用戶「按 Enter 結束」的實現方式！**

---

### 5️⃣ 金額輸入和錯誤處理

```python
try:
    amount = float(input(f"  輸入 {item} 的金額: "))
    flows[item] = amount
except ValueError:
    print("  【錯誤】請輸入有效的數字!")
```

**try-except 塊處理兩種情況：**

| 狀況 | 處理方式 |
|------|---------|
| ✅ 用戶輸入有效數字（如 `1000`） | `float()` 轉換成功 → 存入字典 `flows[item] = amount` |
| ❌ 用戶輸入非數字（如 `abc`） | `float()` 拋出 `ValueError` → 捕捉錯誤 → 顯示錯誤提示 |

💡 **注意：** 若輸入錯誤，迴圈不中斷，用戶可以重新輸入這個項目的金額

---

### 6️⃣ 返回結果

```python
return flows
```

返回填充好的字典，例如：

```python
{
    '銷售收入': 100000.0,
    '收到稅款': 5000.0,
    '其他收入': 2500.0
}
```

# `flow[item] = amount` 詳解

## 代碼作用

```python
flow[item] = amount
```

**將用戶輸入的項目名稱與金額作為鍵值對存入字典。**

| 部分 | 說明 |
|------|------|
| `flow` | 字典對象，儲存現金流項目 |
| `item` | 鍵（key），代表現金流的項目名稱 |
| `amount` | 值（value），代表該項目的金額（浮點數） |

---

## 執行流程

```
用戶輸入項目名稱 (item)
        ↓
用戶輸入金額 (amount) → 轉換為浮點數
        ↓
flow[item] = amount  ← 將此對應存入字典
```

**實例：**

```python
輸入項目: "銷售收入"
輸入金額: 100000
結果: flow["銷售收入"] = 100000.0
```

---

## ⚠️ 代碼問題（Bug）

這段代碼有個變數名錯誤：

| 行號 | 代碼 | 變數名 |
|------|------|--------|
| 第 7 行 | `flows = {}` | `flows` |
| 第 15 行 | `flow[item] = amount` | `flow` |

**問題：** 定義的是 `flows`（複數），但使用的是 `flow`（單數）

**結果：** 會產生 `NameError: name 'flow' is not defined` 錯誤

**修正方式：**

```python
flows[item] = amount  # 使用 flows 而不是 flow
```

## 鍵值對存入字典

> 這裡的意思就是把鍵值對存入字典，是不是？ 

**✅ 完全正確！**

```python
flow[item] = amount
```

就是將一個鍵值對存入字典：

| 部分 | 說明 |
|------|------|
| **鍵（key）** | `item`（項目名稱） |
| **值（value）** | `amount`（金額） |

**實例：**

```python
flow["銷售收入"] = 100000.0
flow["利息收入"] = 5000.0

# 字典最後會是：
{
    "銷售收入": 100000.0,
    "利息收入": 5000.0
}
```

**這是 Python 字典的標準操作方式！**
