print_cash_flow_statement 函數解釋

  函數整體目的

  這個函數用於列印現金流量表，展示公司在特定期間內三類活動的現金流變化：營運活動、投資活動和融資活動。

  ---
  函數結構分解

  1. 計算部分（第24-30行）

  total_operating = sum(operating.values())
  total_investing = sum(investing.values())
  total_financing = sum(financing.values())
  net_cash_flow = total_operating + total_investing + total_financing
  - 計算三類活動的小計
  - 計算本期淨現金流（三個小計的總和）

  2. 表頭部分（第32-35行）

  print("\n" + "=" * 55)
  print(" " * 18 + "現金流量表")
  print("=" * 55)
  - 打印標題「現金流量表」，用等號分隔線和居中格式美化顯示

  3. 三類現金流分段顯示（第37-64行）

  每一類都遵循相同結構：

  print("\n【營運活動現金流】")
  print("-" * 55)
  if operating:                           # 如果有項目
      for item, amount in operating.items():
          print(f"  {item:<25} ${amount:>18,.2f}")
      print("-" * 55)
  print(f"  {'營運活動淨現金流':<25} ${total_operating:>18,.2f}")

  格式解析：
  - {item:<25} — 項目名稱向左對齐，佔25個字符寬度
  - ${amount:>18,.2f} — 金額向右對齐，佔18個字符，使用逗號分隔千位，顯示2位小數
  - 迴圈列出各項目，然後顯示小計

  4. 淨現金流總結（第66-71行）

  print("\n【淨現金流】")
  print("-" * 55)
  print(f"  {'本期淨現金流增減':<25} ${net_cash_flow:>18,.2f}")
  print("=" * 55)
  - 單獨顯示本期淨現金流（三類活動合計）

  5. 現金流量分析（第73-79行）

  print("\n【現金流量分析】")
  print("-" * 55)
  print(f"  營運活動現金流: ${total_operating:>15,.2f}")
  print(f"  投資活動現金流: ${total_investing:>15,.2f}")
  print(f"  融資活動現金流: ${total_financing:>15,.2f}")
  print(f"  {'─' * 45}")
  print(f"  本期淨現金流增減: ${net_cash_flow:>15,.2f}")
  print("=" * 55 + "\n")
  - 以總結形式並列顯示三類活動和最終淨現金流
  - 用分隔線增強可讀性

  ---
  關鍵設計特點

  | 特點   | 說明                                   |
  |------|--------------------------------------|
  | 字典輸入 | 三個參數都是字典，鍵為項目名稱，值為金額                 |
  | 條件檢查 | if operating: 檢查是否有數據，避免空字典時顯示無關的分隔線 |
  | 貨幣格式 | , 格式化為千位分隔，.2f 保留2位小數                |
  | 對齐排版 | 使用 < > 控制左右對齐，讓表格整齊美觀                |
  | 視覺分層 | 使用 = ─ 和 【】 等符號區分層級                  |

  ● 這段代碼的逐行解釋

  if operating:
      for item, amount in operating.items():
          print(f"  {item:<25} ${amount:>18,.2f}")
      print("-" * 55)
  print(f"  {'營運活動淨現金流':<25} ${total_operating:>18,.2f}")

  逐行解析

  | 行   | 代碼                                       | 意思                       |
  |-----|------------------------------------------|--------------------------|
  | 1   | if operating:                            | 檢查 operating 字典是否有資料（非空） |
  | 2   | for item, amount in operating.items():   | 迴圈遍歷字典中的每個鍵值對            |
  | 3   | print(f"  {item:<25} ${amount:>18,.2f}") | 列印 該項目名稱和金額（格式化排版）       |
  | 4   | print("-" * 55)                          | 列印 一條分隔線（只在有資料時才列印）      |
  | 5   | print(f"  {'營運活動淨現金流'...}                | 列印 營運活動的小計               |

  執行流程圖

  operating 字典有資料嗎?
      ↓ 是
    列印每一項目和金額
    列印分隔線「────────」
      ↓ 否 (空字典)
    跳過第 2-4 行
      ↓
    列印「營運活動淨現金流」小計

  具體例子

  假設 operating = {"銷售收入": 100000, "利息收入": 5000}

  輸出結果：
    銷售收入                        $          100,000.00
    利息收入                        $            5,000.00
  ───────────────────────────────────────────────────────
    營運活動淨現金流                $          105,000.00

  ---
  關鍵點

  ✅ if operating: 的作用 — 避免字典為空時，出現不必要的分隔線

  ❌ 如果沒有 if 判斷：
  - 即使沒有項目，仍會列印空白區域和分隔線（不美觀）
