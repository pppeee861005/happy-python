# 附記文件

## Slack MCP 擴展構想

Slack 有 MCP 工具。未來也許可以加以利用，擴展「AI 文明私人學院」中人類與多 Agent 的協作範圍。

可能的探索方向：

- 將 Slack 中的多人討論帶入 Buzz 的協作流程。
- 讓 Agent 整理 Slack 訊息，將有效結論更新至 Buzz Canvas。
- 從 Slack 收集需求，再由 Buzz 中的 Agent 分工、執行與追蹤。
- 將 Buzz 的任務進度或核准需求通知到 Slack。
- 比較 Slack 與 Buzz 在人類—Agent 協作、事件紀錄及知識沉澱上的差異。

## 使用原則

- 現階段先完成 Buzz 的核心協作課程與實驗，不立即導入 Slack。
- 導入前應確認可用的 Slack MCP 工具、權限範圍、資料流與安全限制。
- 不應自動搬運私人頻道、私訊、憑證或敏感資料。
- 跨平台同步應避免重複訊息、循環觸發及責任來源不清。
- Slack MCP 只有在能擴展多人與多 Agent 協作、且有可驗證需求時才正式加入。

## 目前狀態

- 狀態：未驗證的未來構想。
- 優先順序：Buzz 核心課程完成後再評估。
- 下一步：需要擴展外部協作時，先做一次 Slack MCP 能力與權限盤點。
