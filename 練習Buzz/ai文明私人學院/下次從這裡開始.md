## 核心觀念

- Buzz 的 Channel 是持續協作空間。
- Buzz Canvas 是頻道中的共享文件，可保存課程地圖、共同狀態、成果與交接內容。
- Channel 訊息保存討論過程，Canvas 保存目前有效的共同結論。
- Agent 應是有身分、權限與責任範圍的協作成員，不只是聊天機器人。
- 第一次實驗要先把流程做小、做清楚，再增加多 Agent 複雜度。
- `Public` 是目前 Community 內的公開範圍；第一個學習頻道使用 `Ongoing / Public / None`。
- Agent 設定中的 `Only me` 可先保留，讓專案發起者控制直接指派；`Parallelism` 第一次建議設為 `1`，方便追蹤行動。

## 下一個可立即執行的練習

AI 導師建立後，先不要要求它修改 Canvas。先傳送一個只讀任務：

```text
請讀取本頻道的「AI 文明私人學院｜共同課程地圖」Canvas，先不要修改內容。
請回報你看到的：
1. 本頻道核心目標
2. 目前階段
3. 目前參與者
4. 下一個步驟
並說明哪些內容是你實際讀到的，哪些內容尚未確認。
```

這個練習用來驗證第一個 Agent 是否能讀取共享 Canvas，並觀察它是否誠實區分已知與未確認資訊。
