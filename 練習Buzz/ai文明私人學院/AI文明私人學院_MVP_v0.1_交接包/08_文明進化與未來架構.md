# 文明進化路線

> [!IMPORTANT]
> 本路線應由 Buzz 中實際觀察到的多人與多 Agent 協作需求推動。每次演化都要記錄使用的 Buzz 亮點、協作改善、限制與未來可能性。

## v0.1｜共同空間

- 在 Buzz 建立 AI 文明私人學院社群、頻道與 Canvas。
- 由一個 AI 導師與至少兩位人類參與接待、課程與接手實驗。
- 驗證共同狀態是否能透過 Canvas 與事件紀錄延續。

## v0.2｜工具與可追蹤協作

- 讓 Agent 透過 MCP／CLI 讀寫 Canvas 並完成最小任務。
- 驗證身分、權限、人工核准與錯誤處理。
- 從 Buzz 還原一次完整的討論、行動、交接與結果。

## v0.3｜多 Agent 分工

若真實協作需求出現，只拆出第一個必要角色，例如 Scout、Observer 或 Planner。

比較拆分前後的品質、速度、安全、理解與交接成本。沒有明顯改善就合併或移除，不預設 Agent 越多越好。

## v0.4｜跨工具與跨社群擴展

- 評估 Slack MCP 等外部協作介面。
- 研究如何將外部討論沉澱至 Buzz Canvas，而不產生循環觸發、權限混亂或敏感資料外洩。
- 探索不同社群、Agent 與人類之間的可信交接方式。

## v1.0｜未來文明可能性

在已有真實協作證據後，探索：

- Agent-to-Agent 工作與責任網路。
- 人類和 Agent 共同治理資源與權限。
- 可持續演進的共同記憶、課程與服務。
- 由需求形成、可合併、可休眠、可淘汰的 Agent 組織。
- 新型態的學院、公司、社群與人機文明。

## 長期循環

人類提出需求或想像
→ 多人與 Agent 在 Buzz 中協作
→ Canvas 保存共同狀態
→ 工具與工作流程產生成果
→ 事件紀錄支持查證與接手
→ 人類評估價值、限制與風險
→ 形成新的協作實驗
→ 探索更大的未來可能性

核心：

**讓真實協作需求長出組織，讓可追蹤實驗打開未來。**
