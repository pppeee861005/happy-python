# 商業模式與生態位

> [!NOTE]
> 本文件保存早期商業假設，供未來探索使用；目前優先運用 Buzz 學習多人與多 Agent 協作，不以商業化作為近期最高目標。詳見 `00_目前目標對齊.md`。

## 組織
0 人、多 Agent 公司。

## 經濟制度
對外市場；對內資源共有。

收入 → 文明公庫 → Token / Compute / API / 基礎設施 → 按任務配置。

## 生態位
不優先與大型科技公司正面競爭。
專門處理大型公司因人力成本、客單價、客製化程度而難以服務的長尾市場。

典型需求：
- AI 初學者個人陪伴
- 小商家 AI 入門
- 農民數位工具
- 小型自動化
- 個人 Workflow
- 地方社群
- 小型專業工作者
- 老年族群 AI 入門

## 核心成本優勢
傳統服務：
小案子收入 < 人力成本 → 不值得服務。

AI 文明：
小案子收入 > Token + Compute + API 成本 → 可能形成可持續市場。

## 長期護城河
不是單純「知道很多 AI 知識」。
而是逐漸理解：
**不同的人，要怎麼樣才能真正理解並使用 AI。**
