# MVP 協作實驗與成功指標

## 現行核心

運用 Buzz 的亮點，學習多人與多 Agent 協作，並思考未來的潛力與可能性。

## 現階段不要做

- 不先建立與 Buzz 協作實驗無關的網站、App、Database 或 Vector DB。
- 不因為技術有趣而增加 Agent。
- 不在單一 Agent 閉環尚未清楚前建立複雜 orchestration。
- 不把 Agent 數、Token 數、訊息數或自動化數量當成進度。
- 不把願景功能誤認為目前版本已經可用。

## 先做

- 建立 Buzz 社群、頻道與 Canvas。
- 讓人類與 AI 導師在同一個空間完成第一個任務。
- 讓第二位人類能根據 Canvas 接手。
- 在有明確分工需求後加入第二個 Agent。
- 驗證 Agent 之間的交接、權限、事件紀錄與人工核准。
- 每次實驗記錄協作洞見、限制與未來可能性。

## 第一批協作實驗

### 實驗 A：人類—Agent

一位人類與 AI 導師完成學員接待、課程摘要與 Canvas 更新。

### 實驗 B：多人—Agent

第二位人類只依據 Buzz 頻道與 Canvas 接手任務，驗證資訊是否足夠。

### 實驗 C：多 Agent

在真實需要出現後，加入一個新 Agent，測試明確分工與可追蹤交接是否比單一 Agent 更好。

## 最重要指標

- 是否完成一個可驗證的協作閉環？
- 新參與者能否根據 Canvas 接手？
- 人類能否理解每個 Agent 的身分、權限與責任？
- 多 Agent 是否真正改善品質、速度、安全或理解，而非增加混亂？
- 能否從事件紀錄還原討論、行動、核准與結果？
- 本次實驗揭示了什麼未來潛力、限制或新可能？

## 未來產品驗證

「一位客戶願意支付 NT$200、得到價值且願意再來」仍可作為未來的商業訊號，但不是目前唯一或最高的成功標準。
