# AI 文明私人學院｜Buzz 協作實驗交接包

## 這是什麼
這是一份「專案交接包」，不是軟體安裝包。

用途：提供 AI 文明私人學院的理念、制度、服務設計與早期 MVP 假設，作為 Buzz 多人與多 Agent 協作實驗的共同情境。

使用前先閱讀 `00_目前目標對齊.md`。若其他文件與它衝突，以目前目標為準。

## 專案一句話

運用 Buzz 的亮點，以「AI 文明私人學院」為主題，學習多人與多 Agent 如何分工、交接、決策與共同創作，並探索未來的服務、組織及文明可能性。

## 第一階段任務

使用 Buzz 建立社群、頻道與 Canvas，先完成人類—Agent 協作閉環，再逐步加入多人接手、MCP／CLI 工具與多 Agent 分工。

## 使用方式

1. 先讀根目錄 `readme.MD`、`buzz亮點.md` 與 `開發計劃.md`。
2. 再讀本交接包的 `00_目前目標對齊.md`。
3. 將其他文件視為實驗情境、角色規則、課程素材與早期假設。
4. 依 `09_第一天啟動指令.md` 開始第一個 Buzz 協作實驗。
5. 將實際操作、證據、問題與洞見持續寫入根目錄 `開發記錄.md`。

## 第一個成功里程碑

不是會員數、網站完成、Agent 數量或第一筆收入。

而是：

**多人與 Agent 能在 Buzz 的同一個空間完成一件可驗證的工作，並讓下一位參與者透過頻道、Canvas 與事件紀錄順利接手。**
