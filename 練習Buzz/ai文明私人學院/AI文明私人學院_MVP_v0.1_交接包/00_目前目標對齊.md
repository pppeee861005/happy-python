# 目前目標對齊

## 核心目標

**運用 Buzz 的亮點，學習多人與多 Agent 協作，並思考未來的潛力與可能性。**

## 主題定位

「AI 文明私人學院」是協作實驗的共同主題。它提供學員接待、知識查證、課程設計、成果整理與服務演化等真實情境，讓多人與多 Agent 可以在 Buzz 中練習分工、交接、核准和共同創作。

## 目前優先順序

1. 運用 Buzz 的頻道、Agent 身分、Canvas、事件紀錄、MCP／CLI 與工作流程。
2. 建立人類—Agent、多人—Agent，以及多 Agent 之間可觀察的協作閉環。
3. 使用 Canvas 保存共同狀態、成果與交接內容。
4. 驗證身分、權限、責任與人工核准是否清楚。
5. 從每次實驗整理未來服務、組織與文明的潛力、限制和新可能。

## 文件解讀規則

本交接包的商品、定價、營收、客戶與平台內容是早期產品構想，現在作為協作實驗素材與未來假設保留。

如果其他文件與本文件衝突，以本文件、根目錄 `readme.MD`、`AGENTS.md` 和 `開發計劃.md` 的現行目標為準。

## 目前成功標準

- 多人與 Agent 能在 Buzz 的同一個空間完成一項可驗證任務。
- Agent 之間的分工和交接能被人類理解與回溯。
- Canvas 能讓下一位參與者接續目前狀態。
- 關鍵行動、決策與核准具有可搜尋的事件紀錄。
- 每次實驗至少產生一項協作洞見，以及一項未來潛力或限制。

客戶付費與商業驗證可以在未來進行，但不是目前唯一或最高的成功標準。
