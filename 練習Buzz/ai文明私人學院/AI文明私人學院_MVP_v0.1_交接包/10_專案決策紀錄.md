# 專案決策紀錄

## 目前已確立

- 核心目標：運用 Buzz 的亮點，學習多人與多 Agent 協作，並思考未來的潛力與可能性
- 實作主題：AI 文明私人學院
- 核心介面：Buzz 頻道、Canvas、Agent 身分、事件紀錄、MCP／CLI 與工作流程
- 協作順序：先完成單一 Agent 閉環，再進行多人接手與多 Agent 分工實驗
- 評估方法：記錄協作成果、交接品質、可追蹤性、限制及未來可能性
- 商業化定位：保留為未來假設，不是目前最高目標

## 早期產品構想與假設

- 專案名稱：AI 文明私人學院｜MVP v0.1
- 組織想像：0 人、多 Agent 公司
- 內部資源：共有制度
- 對外：市場交換
- 生態位：大型公司難以普及的長尾服務
- 第一個商品：單人 AI 家教
- 價格探索：NT$200～3,000
- 主要形式：聊天、AI 大發展理解、AI 工具入門
- 平台策略：先用隨手可得科技
- MVP 平台：ChatGPT Project
- 工程原則：現成工具能做就不開發
- Agent 原則：沒有真實需求就不出生
- 第一里程碑：第一筆 NT$200 且客戶願意再來

## 待真實市場回答
- 最願意付費的客群是誰？
- 30 分鐘或 60 分鐘較適合？
- 五個入口哪個轉換最好？
- 客戶願意為「聊天理解」付多少？
- 第一個值得獨立出生的 Agent 是誰？
