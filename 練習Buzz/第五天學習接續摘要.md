## 今日學會的任務五要素

一則可執行的 Agent 任務應包含：

1. 目標：要完成什麼。
2. 背景：為什麼要做，以及 Agent 必須知道的資訊。
3. 限制：執行範圍、安全界線及不能做的事情。
4. 輸出格式：成果應如何呈現。
5. 完成條件：人類如何判斷成果合格。

判斷口訣：

```text
執行時不能越過什麼 → 限制
交付後必須具備什麼 → 完成條件
```

## 今日延伸問題：Agent 的連網能力

Peterhuang 發現目前的 Agent 沒有連網能力，因此第五天實機研究任務暫時尚未執行。

目前使用的是 Buzz 的本機 Codex runtime。已討論兩種不同能力：

- 網頁搜尋能力：Agent 可以主動搜尋及閱讀公開網頁。
- 一般網路能力：Agent 執行的命令、套件安裝或 API 呼叫可以對外連線。

建議優先維持 `workspace-write` 沙箱，只開啟必要的網路及搜尋能力，不使用 `danger-full-access`。

預計檢查 Windows 的 Codex 設定檔：

```text
C:\Users\Administrator\.codex\config.toml
```

預計確認或加入：

```toml
sandbox_mode = "workspace-write"
web_search = "live"

[sandbox_workspace_write]
network_access = true
```

注意事項：

- 若設定檔已有 `[sandbox_workspace_write]`，應修改原區段，不可重複建立同名區段。
- 修改後應停止 Agent、重新啟動 Buzz，再重新啟動 Agent。
- 若仍無法使用，應先確認 Buzz 版本，因舊版可能缺少 Codex 網路權限相關修正。
- 網路開啟後仍須限制 Agent 不登入網站、不上傳本機資料、不下載或執行未知檔案。
