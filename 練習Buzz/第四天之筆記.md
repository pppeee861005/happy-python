  如果兩個 Agent 都已加入該 Channel：

  - 你在 Channel 發布的訊息，兩個 Agent 都有權限看到。
  - 但「看得到」不代表一定會主動處理或回答。
  - 使用 @Agent名稱，才是明確指定它回答。

  例如：

  大家好，今天開始第四天練習。

  兩個 Agent 都可能看得到，但不一定回答。

  @fizz 請幫我整理今天的重點。

  這通常只要求 Fizz 回答。

  @fizz @agent2 請你們各自提出三點看法。

  這是同時要求兩個 Agent 回答。

  你可以記住：

  > 加入 Channel＝有資格看見與參與；@Agent＝明確通知並請它處理。

  如果只想和其中一個 Agent 私下交流，不希望另一個 Agent看到，則應使用 DM。
