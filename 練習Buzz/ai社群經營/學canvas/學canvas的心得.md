# Buzz Canvas 學習紀錄

最後更新：2026-08-06

## 學習目標

學會用 Buzz Canvas 維持人類與 Agents 的共同狀態，並逐步應用於「讓一般玩家無門檻參與多人、多 Agent 聊天遊戲」。

## 第 1 課：Canvas 與 Channel（已完成）

我的理解：

> Channel 是大家即時聊天與行動的地方，訊息會持續流動，重要焦點可能逐漸消失；Canvas 是共同黑板，用來讓人類與 Agent 對目前狀態保持一致理解。

已學會：

- Channel 保存正在發生的對話與行動。
- Canvas 保存整理過、公開且之後仍需查閱的共同狀態。
- 尚未公開的角色祕密應放在私人文件，不能放入共同 Canvas。
- 不必把每句聊天搬進 Canvas，只記錄有後續價值的結論。
- 應將「實際觀察結果」與「理論風險」分開記錄，避免把單次測試寫成絕對保證。

### Agent 互相觸發的學習結果

- 本次觀察：Fizz 回覆一次後，因為沒有再次被標記，對話鏈停止。
- 理論風險：兩個 Agent 若在每次回覆中持續互相標記，可能形成事件觸發循環。
- 使用規則：只有需要對方採取行動時才標記；沒有新資訊時保持安靜，不傳送純確認訊息。
- 安全措施：自動流程應設定回合數或花費上限。

## 目前專案狀態

**共同目標：** 讓一般玩家不需要理解 AI、API Key 或 Relay，也能參與多人、多 Agent 聊天遊戲。

**眼前問題：** 一般玩家目前仍有安裝與設定 Buzz 的門檻。

**下一個行動：** 完成第 2 課的六區塊分類練習，再用結果建立正式的專案狀態頁。

## 第 2 課：可接續的狀態頁（進行中）

狀態頁包含六個區塊：

1. 共同目標：最終想完成什麼。
2. 工作規則：所有參與者必須遵守的原則。
3. 目前狀態：現在進行到哪裡。
4. 已完成：有證據支持、真正完成的事情。
5. 下一步：接下來可以執行的具體行動。
6. 待確認事項：尚未測試或仍沒有答案的問題。
