  用來進行即時對話與遊戲。

  Buzz 官方目前將 Canvases 列為可用功能，而且 Agent 也能編輯 Canvas；實際按鈕位置可能隨桌面版更新而改變。Buzz 官方說明
  (https://github.com/block/buzz/blob/main/README.md)

  ## 建立《木馬裡面》Canvas

  1. 開啟 Buzz 桌面程式。
  2. 進入準備遊玩的 Channel，例如 特洛伊木馬。
  3. 在 Channel 標題列、側邊欄或 ＋ 選單中尋找：
      - Canvas

  4. 建立新 Canvas。
  5. 名稱填入：

     《木馬裡面》共同世界

  6. 開啟本機的 奧德塞_木馬裡面/Buzz Channel 共同 Canvas.md。
  7. 全選並複製內容，貼進 Buzz Canvas。
  8. 儲存或完成編輯。
  9. 將 Canvas 加到 特洛伊木馬 Channel，或把它的連結貼入 Channel 並置頂。

  如果介面只有「建立 Canvas」，沒有「附加到 Channel」，先建立 Canvas，再於 Channel 貼上 Canvas 連結即可。

  ## 遊戲開始前

  確認所有真人玩家和五名角色 Agent 都已加入同一個 Channel。Buzz 的權限以 Channel membership 為核心：Channel 成員才能讀寫該
  Channel，因此角色 Agent 是否已加入非常重要。Buzz 安全與權限說明 (https://github.com/block/buzz/security)

  接著在 Channel 發布：

  歡迎進入《木馬裡面》。

  請先閱讀《木馬裡面》共同世界 Canvas。
  這裡沒有固定回合；你可以隨時描述行動，也可以同時 @ 多名角色。

  讀完後，請不要急著發出聲音。
  遊戲即將開始。

  然後由主持人貼出第一則場景訊息。

  ## 遊戲進行時怎麼使用

  Canvas 不需要記錄所有對話。對話本身留在 Channel；只有「所有人都已知道，而且之後仍需要查閱」的內容才寫入 Canvas。

  主持人主要更新 Canvas 最下方的「目前公開狀態」：

  **聲響值：**17／100（安全）
  **進城狀態：**木馬正在往城門移動
  **外界動靜：**右側出現守衛的火把
  **眼前危機：**一把短劍正從刀鞘滑出
  **共同發現：**後腹設有出口機關
  **重要承諾與未完成事件：**玩家小明答應保護安提克勒斯

  建議只在以下情況更新：

  - 聲響值或進城狀態明顯改變。
  - 所有人發現了新的空間或規則。
  - 一項公開承諾會影響後續故事。
  - 眼前危機已經更換。
  - 某項祕密正式被所有人揭露。

  不要把每句對話都搬進 Canvas，否則它會迅速變得難讀。

  ## 絕對不要放進共同 Canvas

  不要貼入：

  - 五名 Agent 的隱藏目的。
  - 誰動過門栓。
  - 尚未發生的事件。
  - 可能結局。
  - 主持人的聲響判定細節。
  - 私下對話與尚未公開的情報。
  - 完整的 人物角色表.md。

  共同 Canvas 對 Channel 內的角色是公開資訊。把祕密放進去，Agent 就可能提前知道答案。

  ## 建議的實際分工

  - **Buzz Canvas：**世界規則、公開角色、最新公開狀態。
  - **Buzz Channel：**玩家發言、角色對話、行動及場景描述。
  - **Agent persona／memory：**每名角色自己的祕密與行為規則。
  - **主持人私人文件：**事件庫、真相與幕後紀錄。

# 課程：用 Canvas 建立人類與 Agents 的共同狀態

建立日期：2026-08-06

## 課程目標

這門課不是把 Canvas 當成普通記事本，而是學會用它建立一個「人類與 Agents 都能快速進入狀態」的共同空間。完成後，你能判斷什麼資訊應放進 Canvas、什麼應留在 Channel，以及如何讓多人、多 Agent 專案在中斷後迅速接續。

## 核心觀念

> Channel 負責事情正在發生；Canvas 負責大家現在共同知道什麼。

Canvas 最適合保存：

- 長期有效的世界規則與工作原則。
- 所有人已經知道的公開資訊。
- 當前狀態、進度與下一步。
- 需要讓新加入的人或 Agent 快速理解的背景。

Canvas 不適合保存：

- 每一句即時對話。
- 尚未公開的祕密與私人設定。
- 很快就失效、沒有後續用途的訊息。
- 未經整理的大量聊天紀錄。

## 課程地圖

### 第 1 課：分清楚 Canvas 與 Channel

學會用「長期／即時」及「公開／私密」兩個維度判斷資訊應放在哪裡。

### 第 2 課：設計一份可接續的狀態頁

建立目標、規則、目前狀態、已完成、下一步與待確認事項六個區塊。

### 第 3 課：讓 Agent 正確讀取與更新

練習給 Agent 明確指令，限制它只能更新指定區塊，並要求保留未知與不確定性。

### 第 4 課：管理公開資訊與祕密

把資料拆成共同 Canvas、個別 Agent 設定、主持人私人文件三層，避免角色提前知道答案。

### 第 5 課：建立社群營運 Canvas

把同一方法用於 AI 社群：記錄社群定位、內容支柱、活動狀態、成員回饋、下一次行動與學習成果。

## 今日學習：第 1 課（2026-08-06）

預計時間：30 分鐘

### 今天要會的事

完成本課後，你應能用一句話說明 Canvas 的用途，並正確替常見資訊選擇存放位置。

### 步驟一：讀懂一句話（3 分鐘）

請讀兩次：

> Channel 是現場；Canvas 是共同記憶。

當人類或 Agent 進入 Channel，Canvas 應該幫助他在短時間內回答三個問題：

1. 我們正在做什麼？
2. 現在進行到哪裡？
3. 接下來最重要的是什麼？

### 步驟二：資訊分類練習（10 分鐘）

先不要看答案，替下列資訊選擇位置：`Canvas`、`Channel`、`私人文件`。

1. 玩家剛說：「我想打開木馬的門。」
2. 所有人都發現木馬後腹有出口機關。
3. 某角色其實打算阻止木馬進城。
4. 目前聲響值為 17／100。
5. Agent 剛講的一句玩笑。
6. 下一次共同測試要確認 Agent 是否會互相無限觸發。

答案：

1. `Channel`：這是正在發生的行動。
2. `Canvas`：這是所有人已知、之後仍有用的事實。
3. `私人文件`：這是尚未公開的角色祕密。
4. `Canvas`：這是所有參與者需要掌握的目前狀態。
5. `Channel`：不必把每句對話搬入共同記憶。
6. `Canvas`：這是會影響後續工作的下一步。

### 步驟三：建立你的第一個狀態區塊（10 分鐘）

在 Buzz Canvas 最下方貼上並填寫：

```markdown
## 目前狀態

**共同目標：**
**現在進度：**
**最新發現：**
**眼前問題：**
**下一個行動：**
**最後更新：**2026-08-06
```

填寫原則：每欄只寫一至三句，讓剛進來的人能在一分鐘內讀完。

### 步驟四：今日實作（5 分鐘）

請用《木馬裡面》目前的狀況，完成以下三格：

```markdown
**共同目標：**
**現在進度：**
**下一個行動：**
```

可參考但不要照抄：共同目標是創造好玩的多人、多 Agent 開放世界；目前已完成自由互動模式與資料分層；下一步是把共同世界內容放入 Buzz Canvas 並進行短測試。
