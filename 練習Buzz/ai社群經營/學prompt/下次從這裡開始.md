# Prompt 學習：下次從這裡開始

最後更新：2026-08-06

## 今日學習主題

學習如何把「記錄今日所學，以利下次展開」寫成清楚、可靠且可執行的 Prompt，並將每天重複的整理流程提煉成 Codex Skill。

## 今天學到的核心觀念

一個可靠的檔案整理 Prompt，應交代四件事：

1. **記錄什麼**：核心觀念、已完成內容、待加強事項與下一個練習。
2. **存在哪裡**：提供完整資料夾與檔案路徑。
3. **如何接續**：說明文件要讓下次的新對話能直接繼續。
4. **如何處理既有內容**：文件存在時要更新並保留仍有效的紀錄，避免重複或錯誤覆蓋。

重複性高、流程固定且需要一致輸出的任務，適合提煉成 Skill。Prompt 負責表達這一次的需求；Skill 負責保存可重複使用的工作流程與品質標準。

## 路徑的學習

- `D:\...\學prompt\下次從這裡開始.md` 中的 `...` 只是人類書寫時的縮寫，不是可靠的實際路徑。
- AI 應先根據已知專案位置推定完整路徑，並明確說明這項推定。
- 若無法可靠推定，應詢問使用者，而不是建立名稱為 `...` 的資料夾。
- 如果目標資料夾不存在，可以先建立資料夾，再建立文件。

```text
D:\gameplace\code\快樂寫程式\練習Buzz\ai社群經營\學prompt\下次從這裡開始.md
```

## 今日完成的練習

原始需求：

```text
現在學習 Prompt：請記錄今日所學，以利下次展開，請建立：下次從這裡開始.md。
```

改進後，Prompt 應明確指定：

- 完整儲存位置。
- 資料夾不存在時要先建立。
- 文件存在時應更新，而不是重複建立。
- 文件需要包含的內容。
- 完成後回報實際儲存位置。

### Skill 實作成果

- 已建立個人 Skill：`daily-learning-handoff`。
- 已完成 Skill 格式驗證。
- 已在本次對話中以 `$daily-learning-handoff` 成功觸發。
- Skill 會建立或更新 `下次從這裡開始.md`，並記錄核心觀念、完成結果、待確認事項與下一個練習。
- Skill 會防止把 `...` 當成真正的資料夾名稱；無法可靠還原路徑時應先詢問。

最可靠的明確觸發方式：

```text
請使用 $daily-learning-handoff 整理今天的學習進度。
```

也可使用自然語言觸發：

```text
請整理今天所學，建立下次可以直接接續的學習文件。
```

明確寫出 `$daily-learning-handoff` 比依賴自然語言判斷更穩定。

## 可重複使用的 Prompt 範本

```text
請把今天的【學習主題】學習進度整理到：
【完整檔案路徑】

文件用途：讓我下次開啟新對話時，可以直接從尚未完成的地方繼續學習。

請記錄：
1. 今天學到的核心觀念。
2. 已完成的練習與結果。
3. 尚未完成或需要加強的部分。
4. 下次課程的起點。
5. 下一個具體練習。
6. 最後更新日期。

如果資料夾不存在，請先建立。
如果文件已存在，請保留仍有效的內容、更新進度並避免重複。
請使用繁體中文與 Markdown，完成後回報實際儲存位置。
```

## 待加強事項

- 練習把模糊需求改寫成包含「目的、輸入、操作規則、輸出格式、完成標準」的 Prompt。
- 學習判斷哪些情況可以讓 AI 合理推定，哪些情況必須先詢問使用者。
- 練習為不同任務設計明確的驗收條件。
- 測試 Skill 在不同學習主題、既有文件與模糊路徑下，是否都能選擇正確位置。

## 下次從這裡開始

進行「Skill 觸發 Prompt 改寫練習」：將下面的句子改成可直接執行且有驗收條件的 Prompt。

```text
用 daily-learning-handoff 幫我整理今天的東西，下次要用。
```

改寫時至少要補上：

- 要整理的主題與內容。
- 完整儲存路徑。
- 資料夾或文件不存在時的處理方式。
- 文件已存在時的更新規則。
- 輸出格式。
- 下次如何接續。
- 完成後如何回報。

建議回答時明確包含 `$daily-learning-handoff`、學習主題、完整路徑、既有文件更新規則，以及完成後的驗證方式。
