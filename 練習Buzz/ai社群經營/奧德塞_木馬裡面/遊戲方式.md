# 《木馬裡面》遊戲方式

## 遊戲概念

《木馬裡面》是運行於 Buzz AI、由對話自然運作的多人、多 Agent 開放世界。五名人類玩家與五名 AI Agent 躲在特洛伊木馬中，共同經歷一段無法預測的故事。它不是回合制劇本遊戲，也沒有必須依序觸發的對話或事件。

玩家以真實的自己進入遊戲，不需扮演預設角色。Agent 可以合作、說謊、違抗、背叛或製造衝突，但所有行為都必須符合自身個性與動機，並以增強玩家的臨場感為原則。

## 參與者

- **人類玩家：**最多五人，透過發言、行動及 `@Agent` 推動故事。
- **AI Agent：**五名，各自擁有公開身分、個性、表面任務與隱藏目的。
- **主持人：**描述世界、喚醒角色、調整聲響值，並判定行動如何改變局勢。

## 初始任務：成功進城

木馬正在被特洛伊人拖入城內。所有人必須控制聲響、處理突發事件，並判斷哪些 Agent 值得信任。

若眾人仍選擇執行木馬計畫，進城的完成條件為：

1. 木馬抵達特洛伊城內。
2. 最終聲響值維持在 20 以下。
3. 木馬尚未被特洛伊人打開。

成功進城只代表局勢跨入新階段，而非整局遊戲結束。玩家也可以放棄、破壞或改寫原定任務；世界會依此形成新的危機與目標。

## 聲響值

聲響值是由主持人管理的遊戲數值，初期不使用真實麥克風測量。

- `0～19`：安全，木馬可以前進。
- `20～39`：警戒，木馬停止或遭到注意。
- `40～100`：危險，特洛伊人可能立即檢查木馬。

玩家爭吵、碰撞木板、使用物品或 Agent 故意搗亂，都可能提高聲響值。安撫衝突、掩蓋聲音或解決事件可以降低聲響值。主持人應在重要行動後公開目前數值與外界反應。

## 自由互動循環

遊戲沒有固定輪次、發言順序或每輪必定發生的事件。互動持續依當下局勢自然流動：

1. 主持人描述環境、眼前危機、聲響值與進城狀態。
2. 主持人可依劇情需要自由 `@` 一名或多名 Agent，讓相關角色感知或介入局勢。
3. 玩家不必等待點名，可隨時發言、描述行動、與 Agent 對話，或同時 `@` 多名 Agent。
4. Agent 不只回應呼叫，也可基於個性、秘密與現況主動交談、爭吵、結盟、隱瞞、阻止他人或採取行動。
5. 主持人在行動足以改變世界時判定後果，更新聲響值、外界反應、角色關係與進城狀態。
6. 新局勢形成後，所有參與者繼續自由介入；主持人只在需要時加入壓力或喚醒新的角色。

玩家可以質問、安撫、欺騙或命令角色，也可以彼此合作、對立，甚至忽略主持人暗示去探索其他可能。沒有任何對話必須觸發，也沒有唯一解法。

第一幕建議遊玩時間為 30～45 分鐘。

## 危機與失敗支線

聲響超標不會立刻結束遊戲，而會逐步升高危機：木馬停止、守衛靠近、敲擊外殼，甚至嘗試開門。玩家必須掩飾聲音、找出肇事者或作出犧牲。

如果木馬遭到打開，遊戲進入「身分暴露」支線；故事仍會繼續，但玩家必須面對完全不同的局勢。

## 主持原則

主持人是世界與節奏的裁判，不是唯一的故事作者。主持人可以在劇情停滯時加入危機，也可以制止沒有後果的對話循環，但不應替玩家決定選擇或強迫故事走向固定結局。

所有判定應服務三個目標：讓行動產生後果、讓衝突保持合理，以及讓玩家持續入戲。

## 進城局勢之後

若木馬成功進城，主持人可以引入「出不去」局勢：玩家發現木馬門栓被人從內部鎖死，並開始追查是誰動了手腳、為何阻止眾人離開。這是可用的局勢，不是必須發生的下一幕；若玩家早已改變任務或出口狀態，主持人應依既有後果改寫或捨棄它。

後續故事可依玩家與 Agent 的選擇，發展成合作、背叛、逃亡，或改寫特洛伊戰爭的歷史。
