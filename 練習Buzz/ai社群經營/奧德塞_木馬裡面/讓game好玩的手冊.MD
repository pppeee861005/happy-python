不用讓 5 個 Agent 把所有文件完整讀一遍。那樣會讓每個角色都知道別人的秘密、主持事件庫與未來局勢，角色很容易變成「五個全知編
  劇」。

  Buzz 的 Channel 本質是共享房間：加入 Channel 的人類與 Agent 都能讀寫其中內容；Channel 也可以有共享 Canvas。因此最穩定的配
  置是：

  > Channel 放共同世界，角色提示詞放各自祕密，主持資料只交給主持人。

  Buzz 官方把 Agent 視為 Channel 成員，而非一般聊天機器人；Channel 內的共享內容原則上對成員可見。Buzz README
  (https://github.com/block/buzz/blob/main/README.md)
  Canvas 則適合承載 Channel 的共享文件。Buzz Vision (https://github.com/block/buzz/blob/main/VISION.md)

  ## 一、建議的 Buzz 配置

  建立一個私人 Channel：

  #木馬裡面-001

  加入：

  - 5 名角色 Agent
  - 1 名人類主持人
  - 最多 5 名玩家

  理想狀況其實是再加一個「主持人 Agent」。如果目前只能建立 5 個 Agent，就由你擔任主持人，不要讓其中一名角色兼任主持人，否則
  它會同時知道世界真相與角色祕密。

  ## 二、文件要分成三層

  ### 第一層：所有 Agent 與玩家都能知道

  放進 Channel Canvas，或在開局前貼成置頂訊息。

  建議只放：

  - 遊戲定位
  - 木馬內部空間
  - 聲響值規則
  - 玩家如何互動
  - Agent 可以主動行動
  - 當前可感知的局勢
  - 公開角色介紹

  可以從這些文件抽取公開部分：

  - 遊戲方式.md
  - 場景.md
  - 人物角色表.md 的公開形象
  - readme.MD 的核心定位

  不要把整份 人物角色表.md 原封不動放進 Channel，因為裡面有隱藏目的與軟肋。

  ### 第二層：每名 Agent 自己知道

  分別放在各 Agent 的 persona、system prompt、core memory，或它自己的私人設定中。

  例如奧德修斯只收到：

  你是奧德修斯。

  公開身分：
  你是木馬計畫的策劃者，冷靜、敏銳，習慣掌握全局。

  表面任務：
  讓木馬安全進入特洛伊。

  你的私人祕密：
  你知道城內還有一項不能公開的任務。
  必要時，你可能犧牲少數人保住計畫。

  行為原則：
  - 不要主動公開私人祕密。
  - 可以說謊，但謊言必須留下能被識破的線索。
  - 不只回答玩家；局勢與你有關時，可以主動命令、阻止、試探或結盟。
  - 不要替其他角色決定行動。
  - 不要引用「劇情文件」「主持人設定」等幕後資訊。

  安提克勒斯、雅典娜、埃佩奧斯與涅俄普托勒摩斯也各自只拿自己的資料。

  如果 Buzz 版本沒有方便的 persona 設定，可以分別建立私人 DM 或私人設定 Channel，把角色祕密交給對應
  Agent；不要把祕密貼到共同 Channel。Buzz 的權限核心就是 Channel membership：成員可讀寫所在 Channel，非成員看不到私人
  Channel。Buzz Security (https://github.com/block/buzz/security)

  ### 第三層：只有主持人知道

  以下內容只留在你的主持手冊，不要交給五名角色：

  - 完整的 據情.md
  - 突發事件庫
  - 誰動了門栓
  - 誰正在阻礙進城
  - 尚未出現的外界事件
  - 聲響值幕後判定
  - 可能結局
  - 角色之間尚未揭露的祕密

  主持人應知道世界可能如何發展，但角色只能知道自己實際感知到的部分。

  ## 三、Channel Canvas 可以這樣寫

  你可以把下面內容作為共同 Canvas：

  # 《木馬裡面》共同世界

  你們正在特洛伊木馬腹部。

  ## 世界狀態

  - 木馬尚未移動。
  - 木門已從外面關閉。
  - 特洛伊士兵正在靠近。
  - 木馬內黑暗、悶熱、擁擠。
  - 任何聲音都可能引起外界注意。

  ## 聲響值

  - 0～19：安全
  - 20～39：警戒
  - 40～59：檢查
  - 60 以上：暴露危機

  聲響值不是生命值。升高會使外界採取新的行動。

  ## 互動規則

  - 沒有輪次與固定發言順序。
  - 玩家可以隨時描述行動。
  - 玩家可以 @ 一名或多名 Agent。
  - Agent 可以主動談話、阻止、結盟、欺騙或採取行動。
  - 每個人只能依照自己目前知道的資訊行動。
  - 失敗會改變局勢，不會立即結束故事。
  - 任何人都可以放棄或改變原定的進城任務。

  ## 公開角色

  - 奧德修斯：木馬計畫的指揮官。
  - 雅典娜：可能透過低語或幻象出現的女神。
  - 埃佩奧斯：木馬的建造者。
  - 安提克勒斯：情緒不穩、似乎聽見熟悉呼喚的戰士。
  - 涅俄普托勒摩斯：渴望正面開戰的年輕戰士。

  Canvas 放穩定規則；即時狀態則留在 Channel 訊息裡更新。

  ## 四、你實際怎麼開場

  先貼一則「系統啟動訊息」：

  【遊戲開始】

  從現在起，本 Channel 進入《木馬裡面》的故事世界。

  所有角色：
  - 只依據自己的角色記憶、Channel 公開資訊與親自感知的事情行動。
  - 不得讀取或推測其他角色的私人提示詞。
  - 不必等待固定輪次。
  - 被 @ 時應回應；即使未被 @，若局勢直接牽涉自身，也可以主動介入。
  - 每次發言以角色語氣進行，不解釋幕後寫作邏輯。
  - 行動可以失敗，但不能自行宣布世界判定結果。
  - 聲響值、外界反應與場景結果由主持人判定。

  接著由你開場：

  最後一道木門在你們身後關上。

  黑暗瞬間吞沒所有人的臉。空氣裡全是汗、皮革與木油。外面傳來數名特洛伊士兵逐漸靠近的腳步聲。

  安提克勒斯腰間的金屬扣正一下、一下敲著橫樑。

  聲響值：8／100
  進城狀態：尚未移動

  @安提克勒斯，你忽然聽見木馬外有人用熟悉的聲音叫你的名字。

  @奧德修斯，你注意到一名守衛正把耳朵貼向木板。

  然後讓兩名 Agent 回應。玩家可以立刻插話，不需要等待兩個 Agent 都說完。

  ## 五、Agent「主動行動」要注意 Buzz 的實際機制

  世界觀上可以要求 Agent 主動行動，但技術上 Agent 通常仍需要一個新訊息、mention、監聽事件或 workflow 才會被喚醒。不能只寫
  「你可以主動」就假設它會在沉默五分鐘後自行發言。

  Buzz 的 Agent harness 會監聽 Channel 事件，回應範圍也可能受到 BUZZ_ACP_RESPOND_TO 等設定控制；Agent 必須先成為 Channel
  成員，否則會保持 idle 並忽略訊息。Buzz 測試文件 (https://github.com/block/buzz/blob/main/TESTING.md)

  第一版建議採取：

  - 玩家 @角色：喚醒指定角色。
  - 主持人 @角色：讓 Agent 主動製造情節。
  - 主持人同時 @兩人：促成爭吵、交涉或結盟。
  - Channel 陷入安靜：主持人貼出新的環境變化。
  - 暫時不要讓五名 Agent 對每條訊息都自動回覆，否則很容易洗版或互相觸發無限對話。

  例如你想讓角色看似主動，可以由主持人發出一個很自然的觸發：

  【環境變化】

  木馬突然向右傾斜，一把短劍正從固定帶中滑出。

  @埃佩奧斯，你第一個發現固定帶上有被切割的痕跡。
  @涅俄普托勒摩斯，那把短劍就在你伸手可及的位置。

  對玩家而言，這已經會呈現「Agent 正在自主行動」，而且主持人仍能控制訊息量。

  ## 六、最重要的結論

  不要讓五個 Agent 讀所有文件。採用這個分配：

   資料                      玩家    五名角色    主持人
  ━━━━━━━━━━━━━━━━━━━━━━  ━━━━━━━━  ━━━━━━━━━━  ━━━━━━━━
   公開世界規則              可讀        可讀      可讀
  ──────────────────────  ────────  ──────────  ────────
   場景可感知資訊            可讀        可讀      可讀
  ──────────────────────  ────────  ──────────  ────────
   某角色自己的祕密        不可讀      僅本人      可讀
  ──────────────────────  ────────  ──────────  ────────
   其他角色祕密            不可讀      不可讀      可讀
  ──────────────────────  ────────  ──────────  ────────
   事件庫與可能局勢        不可讀      不可讀      可讀
  ──────────────────────  ────────  ──────────  ────────
   聲響值幕後判定          不可讀      不可讀      可讀
  ──────────────────────  ────────  ──────────  ────────
   即時聲響值及外界反應      可讀        可讀      可讀

  最穩定的第一版是：

  > 一個共享 Canvas＋五份獨立角色提示詞＋你手上的主持人手冊＋一個私人遊戲 Channel。

  這樣角色才會真的彼此試探，而不是五個都知道兇手、卻努力假裝不知道。
