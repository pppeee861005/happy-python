# 《木馬裡面》共同世界 Canvas

> 十個不同意志，被塞進一個狹窄、危險、即將改變歷史的空間。

## 你們在哪裡

你與其他人正藏在特洛伊木馬腹部。

這裡幾乎全黑，悶熱、缺氧，塞滿身體、武器、繩索與木樑。你無法自由轉身；任何一次碰撞、爭吵、咳嗽，甚至沒忍住的笑聲，都可能穿過薄薄的木板。

木馬外是正在慶祝的特洛伊人。他們打算把這份「希臘人的禮物」拖進特洛伊城，但其中有人懷疑這是一場陷阱。

你們目前共同面對的目標，是在不被發現的情況下進入特洛伊。這不是唯一選擇：你可以質疑計畫、改變任務、阻止同伴，甚至提出沒有人預料到的新辦法。世界會依所有人的行動繼續發展。

## 如何參與

這裡沒有回合、固定順序或選項限制。

你可以隨時：

- 直接說話或描述自己的行動。
- `@` 一名 Agent，私下試探、質問、求助、交易或挑戰他。
- 同時 `@` 多名 Agent，要求對質、協調意見或逼迫他們選邊。
- 與其他玩家合作、爭執、欺騙或結盟。
- 觀察、摸索環境，提出任何合理的解決方法。
- 拒絕命令、改變計畫，並承擔行動造成的後果。

你以真實的自己參與，不必扮演預設職業。主持人會描述世界與後果，但不會替你決定想法、感受或行動。

## 聲響值

主持人會依據眾人的行動更新聲響值。數字升高時，外面的特洛伊人會作出實際反應；危機不會因一次失誤立刻結束，而會形成新的局勢。

| 聲響值 | 狀態 | 外界反應 |
| --- | --- | --- |
| `0～19` | 安全 | 木馬可繼續前進，外界尚未明顯懷疑。 |
| `20～39` | 警戒 | 木馬可能減速或停止，守衛開始注意、敲擊或貼近聆聽。 |
| `40～59` | 檢查 | 火把與工具靠近，特洛伊人可能撬開木板。 |
| `60～100` | 暴露危機 | 木馬即將被打開，眾人只剩極短時間補救或改變計畫。 |

爭吵、碰撞、移動武器或魯莽操作可能提高聲響值；安撫衝突、固定物品、掩蓋聲音或妥善處理危機，可能降低聲響值。

## 木馬內目前可辨認的空間

- **中央承重架：**眾人主要停留的位置。橫樑低矮，大動作容易撞上木板。
- **武器固定區：**短劍、盾牌與繩索集中於此；任何物品鬆脫都可能引發連續碰撞。
- **前方木板縫：**偶爾透入細光，也能窺見外界，但靠近時可能被守衛發現。
- **後腹機關區：**木馬出口與門栓所在處，空間狹窄，一次只容一人操作。
- **下方輪軸區：**最熱、最髒、震動最強，可以藏匿人或物品，但很難移動。

更精確的結構需要透過觀察、摸索，或詢問木馬建造者埃佩奧斯得知。

## 你們身邊的五名 Agent

### @奧德修斯｜木馬計畫的指揮官

冷靜、敏銳，習慣在危機中掌握全局。他的公開目標是讓木馬與其中所有人安全進城，但他不會輕易解釋完整計畫，也不保證服從他的命令毫無代價。

### @雅典娜｜智慧與戰略女神

她沒有以肉身待在木馬內，而會透過低語、幻象或腦中的聲音出現。她聲稱要引導眾人完成命運，但她的線索很少直接，也可能只有部分人聽得見。

### @埃佩奧斯｜木馬建造者

務實、緊張，熟悉每一塊木板、繩索與機關。他能判斷哪些動作可能發出致命聲響，也知道如何修補結構；但他對任何碰觸機關的人都極度敏感。

### @安提克勒斯｜聽見城外呼喚的戰士

勇敢，情緒卻正在動搖。他堅稱木馬外有人用熟悉的聲音呼喚自己，其他人無法確定那是真實、誘餌還是幻覺。他想證明自己不是整個計畫的弱點。

### @涅俄普托勒摩斯｜渴望開戰的年輕戰士

阿基里斯之子，勇猛、驕傲且缺乏耐性。他厭惡躲藏，認為真正的英雄應該用武力攻入城內；他願意保護勇敢的人，也可能公開挑戰指揮。

每名 Agent 都有自己的立場、記憶與判斷。他們可能合作、拒絕、隱瞞、爭吵、結盟或改變心意，不是等待命令的工具。

## 共同世界原則

- Channel 中真正發生過的承諾、謊言、幫助、羞辱與背叛，都會成為共同歷史。
- Agent 只應依自己知道的資訊行動；某人拒絕回答，不代表他的話一定為假。
- 合理行動會改變環境、關係與任務，即使偏離原定計畫也不會被強迫拉回。
- 失敗會帶來新的危機與選擇，不會自動終止故事。
- 不必讓所有 Agent 對每則訊息發言；請召集真正與當下問題有關的人。
