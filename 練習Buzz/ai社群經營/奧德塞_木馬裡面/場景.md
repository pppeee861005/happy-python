# 《木馬裡面》場景設定

## 場景核心

故事發生在特洛伊木馬腹部。這裡不是宏偉的英雄殿堂，而是一個塞滿人、武器、繩索與汗臭味的狹小木箱。

所有人都離彼此太近：膝蓋頂著陌生人的腰，手肘壓在別人的腿上，想轉身就會碰到木板。外面是正在慶祝的特洛伊人；裡面任何一次咳嗽、爭吵、發抖，甚至放屁，都可能讓整場戰爭提前結束。

場景應同時具有三種氣氛：

- **壓迫：**黑暗、缺氧、悶熱，沒有人能自由移動。
- **危險：**木板外只隔著敵人的耳朵與武器。
- **荒謬：**英雄也會腳麻、流汗、肚子痛，並把責任推給別人。

## 木馬內部空間

木馬腹部可分成五個區域，但彼此沒有真正的隔間：

1. **前胸觀察縫：**能看見有限的外部光影，也是最容易被外面發現的位置。
2. **中央承重架：**眾人主要停留處。橫樑低矮，任何大動作都可能撞擊木板。
3. **武器固定區：**短劍、盾牌與繩索集中於此。固定帶鬆脫時會造成連續碰撞。
4. **後腹機關區：**埃佩奧斯設計的出口與門栓所在處。空間只容一人蹲著操作。
5. **下方輪軸區：**最熱、最髒，也最接近路面震動；可以藏人或物品，但移動非常困難。

玩家不必一開始知道完整結構。主持人應在觀察、摸索或詢問埃佩奧斯後逐步揭露。

## 感官描寫

主持人每次更新局勢時可選擇一至兩種感官描寫，不必一次全部使用。

### 聲音

- 木輪碾過碎石，震動沿著骨頭往上爬。
- 外面有人唱歌、敲盾、爭論該不該燒掉木馬。
- 繩索拉緊時發出像低聲呻吟的摩擦聲。
- 某人的牙齒不停打顫，節奏清楚得令人恐慌。
- 木板傳來三下敲擊，停頓後，又敲了兩下。

### 氣味

- 汗、皮革、木屑、油脂與長時間沒有清洗的身體。
- 潮濕衣物貼在皮膚上，空氣像被反覆呼吸過。
- 有人放屁，所有人都知道，卻沒有人願意承認。
- 木板縫隙偶爾飄入城外的酒、煙與烤肉味。

### 觸感與溫度

- 肩膀貼著陌生人的背，無法確定對方是在呼吸還是發抖。
- 木刺扎進掌心，但拔出來可能必須改變姿勢。
- 溫度不斷升高，金屬武器摸起來也帶著體溫。
- 木馬轉彎時，所有人的重量會突然壓向同一側。

### 視覺

- 木馬內幾乎全黑，只剩木板縫間切進來的細光。
- 光線掠過時，只能看見一隻眼睛、半張臉或刀刃反光。
- 玩家無法確認遠處的影子屬於誰。

## 進城狀態與可能局勢

進城狀態用來說明木馬在世界中的位置，不是關卡、回合計數或事件觸發表。主持人可依玩家行動、聲響值與外界反應讓木馬前進、停止、折返、被拆開或轉往別處。以下局勢可以跳過、重疊、倒轉或被玩家徹底改寫。

### 可能局勢：剛被封閉

希臘人剛離開海岸，木馬內的出口被鎖上。眾人第一次意識到這裡比想像中更小、更熱，也沒有人能在不碰到別人的情況下移動。

用途：介紹空間、角色與聲響值，讓玩家決定信任誰。

### 可能局勢：在海灘被發現

特洛伊人來到海灘。他們敲擊木馬、查看接縫，並爭論這是神的禮物還是希臘人的陷阱。

用途：建立外界威脅，讓第一次安靜判定真正具有後果。

### 可能局勢：開始移動

繩索猛然繃緊，木馬向前傾斜。所有人撞向同一側，一件沒有固定好的物品開始滑動。

用途：製造必須立即處理的物理危機。

### 可能局勢：停在城門前

木馬停下。城門似乎不夠高，外面有人提議拆掉木馬、擴大城門，或直接在原地焚燒祭神。

用途：讓等待本身成為壓力，鼓勵 Agent 挑起衝突。

### 可能局勢：遭到近身檢查

有人繞著木馬模仿眾人最熟悉的聲音，呼喚藏身者的名字。安提克勒斯確信自己聽見所愛之人，雅典娜則可能向不同玩家提供不同說法。

用途：把角色秘密、信任與聲響機制拉到最高點。

### 可能局勢：進入特洛伊

木輪越過城門石縫，歡呼聲從四面包圍木馬。如果最終聲響值低於 20、木馬未被打開，第一幕成功。

但當眾人準備離開時，門栓無法開啟。有人已經從內部動過手腳。

用途：完成第一幕目標，銜接第二幕「出不去」。

## 突發事件庫

主持人可依節奏選用，不需全部觸發。

| 事件 | 立即危機 | 可延伸的懷疑 |
| --- | --- | --- |
| 有人放屁 | 安提克勒斯忍不住咳嗽或笑出聲 | 是自然反應，還是有人故意製造混亂？ |
| 無法停止的顫抖 | 武器與木板規律碰撞 | 恐懼、受傷，還是秘密訊號？ |
| 短劍滑出刀鞘 | 必須在落地前接住 | 固定帶是否被人割斷？ |
| 木刺扎傷玩家 | 疼痛、流血且不能大叫 | 誰願意幫忙，誰只在乎聲響值？ |
| 外面傳來哭聲 | 有人相信親友就在附近 | 聲音是真的、模仿，還是雅典娜的試探？ |
| 木馬突然傾斜 | 眾人及武器滑向同一側 | 埃佩奧斯是否隱瞞結構問題？ |
| 門栓發出摩擦聲 | 後腹似乎有人正在移動 | 是機關自行鬆動，還是內部破壞？ |
| 守衛敲擊暗號 | 敲擊似乎等待回應 | 回應可能得到盟友，也可能暴露所有人。 |
| 玩家開始缺氧 | 必須靠近觀察縫換氣 | 縫外正好站著一名守衛。 |
| 不明物體爬過腿部 | 有人差點驚叫或踢動 | 是老鼠、昆蟲，還是一隻人的手？ |

## 聲響值與環境反應

- **0～9｜死寂：**可以聽見呼吸與心跳；木馬穩定前進。
- **10～19｜安全：**外界尚未懷疑，但細小事故正在累積。
- **20～29｜注意：**木馬減速，外面的談話聲突然降低。
- **30～39｜警戒：**木馬停止，守衛開始敲擊或貼近木板聆聽。
- **40～59｜檢查：**火把靠近縫隙，有人準備撬開木板。
- **60 以上｜暴露危機：**木馬即將被打開，玩家只剩一次補救行動。

聲響值不是單純的懲罰。每次升高都應帶來新的外界反應、選擇或情報，而不是只公布數字。

## 主持節奏原則

- 每次只推出一個清楚的眼前危機。
- 玩家有創意地處理事件時，應讓方法有效並產生合理代價。
- 安靜太久就加入身體問題；爭吵太久就讓外界作出反應。
- 荒謬事件之後要接回危險，避免故事只剩笑話。
- 恐怖事件之後可加入尷尬或人性時刻，讓情緒有起伏。
- 不預先指定破壞者；讓玩家與 Agent 的選擇決定誰真正跨過界線。
