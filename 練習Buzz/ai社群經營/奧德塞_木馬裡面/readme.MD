# 《木馬裡面》

## 專案定位

《木馬裡面》是一個運行於 Buzz AI、由對話自然運作的多人、多 Agent 開放世界，也是「將 AI 社群經營成主題樂園」的第一個實驗場景。它不是回合制劇本遊戲：主持人點燃世界，故事則由所有參與者共同失控。

五名人類玩家與五名 AI Agent 被放進特洛伊木馬內。玩家以真實的自己參與，不需扮演預設角色；故事則由人類選擇、Agent 行動與主持人判定共同形成。沒有人預先知道劇情會走向荒謬、恐怖、背叛，還是合作。

> 十個不同意志，被塞進一個狹窄、危險、即將改變歷史的空間。

## 核心體驗

- **多人、多 Agent：**人類與 AI 同時參與並互相影響。
- **不可預測：**Agent 可以說謊、違抗、結盟或背叛。
- **高度臨場感：**所有事件都圍繞木馬內的幽暗、擁擠與危險展開。
- **可以重玩：**參與者與選擇不同，每次都會形成新的故事。
- **共同創作：**主持人管理世界，但不預寫唯一結局。

Agent 擁有最大的發揮空間，但「不可控」不等於隨機胡鬧。每個行動都應符合角色個性、當下情境及隱藏目的，最重要的目標是讓玩家入戲。

## 遊戲形式

- **平台：**Buzz AI
- **Channel：**特洛伊木馬
- **人類玩家：**最多五名
- **AI Agent：**五名
- **互動方式：**玩家透過發言、行動描述與 `@Agent` 推動劇情，也可以同時呼叫多名 Agent。
- **互動節奏：**沒有輪次與固定發言順序；玩家與 Agent 都可隨時主動介入。
- **初期主持：**由一名人類主持人管理節奏與判定。

## 第一幕：進城

木馬正被特洛伊人拖入城內。玩家與 Agent 必須保持安靜、處理突發事件，並判斷彼此是否值得信任。

第一幕使用虛構的「聲響值」作為壓力機制：

- `0～19`：安全，木馬可以繼續前進。
- `20～39`：警戒，木馬可能停止或引起注意。
- `40～100`：危險，特洛伊人可能直接檢查木馬。

聲響值由主持人依據玩家與 Agent 的行動調整。有人可能為了自己的目的故意提高聲響值、阻礙木馬進城。

木馬成功抵達城內、未被打開，且最終聲響值低於 20，即完成第一幕。聲響超標不會立即結束遊戲，而會引發守衛靠近、木馬受檢等危機；若身分暴露，故事將轉入另一條支線。

## 主持人的角色

主持人是世界與節奏的裁判，負責：

- 描述木馬內外的環境與事件。
- 判定玩家行動造成的後果。
- 調整並公布聲響值。
- 決定木馬能否繼續前進。
- 在劇情停滯時加入危機。
- 避免對話失去方向或變成無意義的雜訊。

主持人不替玩家選擇，也不強迫故事抵達固定結局。

## 可用的故事局勢

目前準備三組可供主持人取用的局勢，並非固定順序或玩家必須遵循的軌道：

1. **進城：**維持安靜，處理木馬內部的衝突。
2. **出不去：**成功進城後，眾人發現木馬門栓被人從內部鎖死。
3. **選擇：**執行原定計畫、背叛同伴，或共同改寫歷史。

玩家可以跳過、逆轉或放棄其中任何局勢，包括拒絕進城。聲響值、木馬空間與外部敵人是持續運作的世界規則；三組局勢與事件庫只是主持素材。後續故事依玩家與 Agent 的選擇自然發展。

## 目前開發重點

第一版先驗證一場 30～45 分鐘的第一幕是否好玩，不急著完成整座「AI 主題樂園」。下一步包括：

1. 設計五名 Agent 的公開身分、個性、表面任務與隱藏目的。
2. 撰寫第一幕開場及突發事件。
3. 建立主持人的聲響值判定準則。
4. 在 Buzz AI 進行首次小規模試玩。
