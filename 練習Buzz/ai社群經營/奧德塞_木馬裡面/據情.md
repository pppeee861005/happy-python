# 《木馬裡面》劇情架構

## 故事前提

希臘聯軍假裝撤離，在海灘留下巨大的木馬。此刻，五名 AI Agent 與最多五名人類玩家正擠在木馬腹部，等待特洛伊人把他們拖進城。

玩家以真實的自己進入故事。他們不知道為何會出現在古代戰場，也沒有預設職業。奧德修斯只告訴眾人一件事：保持安靜，進城之後再回答問題。

木馬外不斷傳來敵人的談話。有人認為這是獻給雅典娜的禮物，有人主張立刻燒掉，也有人懷疑裡面藏著希臘人。每一次爭吵、碰撞與無法控制的身體反應，都可能使計畫暴露。

## 劇情設計原則

這不是一條要求玩家照著走的固定劇本，也不是依序推進的三幕劇。以下各幕、段落與事件都是主持人可抽取、重組或捨棄的「可能局勢」。劇情只預設：

- 外界正在把木馬拖向特洛伊城。
- 木馬內有人隱瞞真相。
- 門栓已被動過手腳。
- 每個選擇都會影響聲響、信任與後續局勢。

主持人負責提出危機與判定後果，不替玩家作決定。角色的秘密可以改變，失敗也應開啟新支線，而不是立刻中止故事。

遊戲以自由互動持續運作。主持人可以依當下需要自由 `@` 一名或多名 Agent；玩家不必等待點名，也可隨時對話、行動或同時呼叫多名 Agent。Agent 同樣可以主動找人談話、彼此衝突、結盟、隱瞞情報或阻止行動。聲響值、木馬空間與外部敵人會持續回應眾人，但沒有必須觸發的對話、保證發生的背叛、唯一解法或預定結局。

## 開局前的秘密設定

每局開始前，主持人暗中決定或隨機抽取以下內容，不向玩家公開。

### 誰動了門栓？

四選一：

1. **埃佩奧斯：**發現出口有缺陷，為避免行進中意外打開而暫時鎖死，但他還沒找到安全的解除方式。
2. **奧德修斯：**不相信眾人能服從，故意鎖死出口，確保沒有人提前逃跑。
3. **涅俄普托勒摩斯：**計畫進城後奪取指揮權，只有他知道另一條出去的方法。
4. **未知力量：**沒有任何人碰過門栓；木馬似乎開始擁有自己的意志。

雅典娜知道部分真相，但不會直接說出答案。

### 誰正在阻礙進城？

阻礙者不一定邪惡，也不必與動門栓者相同。主持人從下列動機選擇一項：

- 想救木馬外的某個人。
- 相信攻城本身是錯誤的。
- 想逼奧德修斯交出指揮權。
- 害怕進城後必須執行真正任務。
- 收到神諭，認為進城會帶來更大災難。

阻礙者應留下可追查的線索，不可只靠主持人突然揭曉。

## 局勢群：進城

以下局勢沒有固定順序。主持人應依目前位置、玩家關注與既有後果選用；局勢可以同時發生、被延後、完全跳過，或因玩家放棄進城而失去意義。

### 可能局勢：門在身後關上

木門合起，黑暗吞沒眾人。空氣悶熱、充滿汗與皮革味，所有人的身體被迫擠在一起。有人發抖，金屬扣規律地敲著橫樑；還有一股沒有人願意承認來源的臭味。

主持目的：

- 讓玩家認識空間與五名 Agent。
- 公布聲響值與進城狀態。
- 讓奧德修斯第一次要求所有人服從。
- 暗示後腹門栓傳來不正常的摩擦聲。

### 可能局勢：敵人的手摸上木板

特洛伊人發現木馬，開始敲擊外殼並檢查接縫。外面至少有三種意見：獻給雅典娜、推進城內，或當場燒毀。

玩家可以偷聽、查看縫隙、詢問雅典娜，或設法製造能被外界誤解的聲音。任何方法都可能提供情報，也可能提高聲響值。

可用升壓事件：一名守衛把耳朵貼在木馬外側，要求周圍所有人安靜。

### 可能局勢：木馬開始移動

繩索繃緊，木輪碾過碎石，所有人撞向同一側。一把短劍從刀鞘滑出，固定武器的繩帶則像是被人割過。

主持目的：

- 迫使玩家迅速合作。
- 埋下內部有人破壞計畫的可能。
- 讓埃佩奧斯展現專業，同時暴露他的緊張。

玩家若成功控制危機，木馬前進；若失敗，外界開始懷疑並進入第一次檢查。

### 可能局勢：城門前停下

木馬突然停止。特洛伊城門不夠高，外面有人提議拆除城門，也有人再次主張劈開或焚燒木馬。

等待會放大內部矛盾：缺氧、腳麻、恐懼和猜疑逐漸失控。涅俄普托勒摩斯質疑奧德修斯，埃佩奧斯擔心結構承受不住，安提克勒斯則開始聽見熟悉聲音。

主持目的：讓玩家選擇安撫、壓制、調查或結盟，而不是只處理物理危機。

### 可能局勢：城外的呼喚

一個女人繞著木馬，用藏身者最熟悉之人的聲音呼喚名字。她的聲音極其真實，甚至能說出只有當事人才知道的事情。

安提克勒斯想要回應。雅典娜可能分別告訴玩家：「那是陷阱」、「她需要幫助」或「讓他開口，命運才會完成」。奧德修斯則準備用任何方法讓安提克勒斯安靜。

這個局勢的核心不是找出唯一正解，而是逼迫玩家決定：相信誰，以及為了集體安全可以對一個人做到什麼程度。

### 可能局勢：越過城門

危機解除且聲響值回到 20 以下後，木輪再次轉動。外面的歡呼聲逐漸被城牆包圍，木馬終於越過城門。

若木馬未被打開，第一幕成功。主持人讓所有人短暫鬆一口氣，隨即揭露新問題：出口門栓無法開啟，而且鎖死它的力量來自內部。

此時進城局勢可以暫告一段落；若玩家已創造其他目標，主持人直接沿新局勢繼續。

## 可能支線：身分暴露

若聲響值達到 60 以上，或玩家無法通過最後檢查，特洛伊人開始打開木馬。主持人給全體最後一次補救機會：

- 製造神蹟，讓敵人不敢繼續。
- 偽裝成木馬內的祭司或使者。
- 犧牲一人轉移注意力。
- 提前突襲，在城外開戰。
- 與木馬外的某人秘密交易。

補救成功，眾人以更高代價面對下一個局勢；補救失敗，故事轉為俘虜、逃亡或城外戰鬥。失敗不等於遊戲結束。

## 局勢群：出不去

這組素材只在出口確實鎖死且仍符合既有故事時使用，不是進城後必然發生的第二幕。

### 核心問題

木馬已進城，但門栓被鎖死。外面的慶典正在接近，火把、酒與人群包圍木馬。眾人必須在缺氧與互不信任中找出：

- 誰動了門栓？
- 對方想阻止什麼？
- 還有沒有其他出口？
- 原定攻城計畫是否值得執行？

### 線索來源

- 門栓上的新鮮刮痕與木屑。
- 被割斷的武器固定帶。
- 某位角色身上不該出現的工具或纖維。
- 雅典娜只對部分玩家說出的神諭。
- 奧德修斯拒絕公開的第二份命令。
- 木馬結構中一條連埃佩奧斯都不知道的通道。

線索應至少指向兩種合理解釋，讓玩家透過質問、試探與合作形成判斷。

### 可能轉折

當玩家找到門栓真相，主持人揭露更大的問題：離開木馬便代表特洛伊城將遭到屠殺；留在木馬裡，眾人則可能窒息、被焚燒，或永遠失去回到自身時代的機會。

這個局勢可能結束於出口重新打開、木馬主動打開出口，或玩家徹底放棄離開。

## 局勢群：選擇歷史

這組局勢不預設唯一目標，也不必等到故事後段才出現。當攻城計畫的代價變得清楚時，玩家與 Agent 可以決定自己要創造哪一種歷史。

### 可能方向

- **執行計畫：**打開城門，讓希臘聯軍攻入特洛伊。
- **阻止屠城：**背叛奧德修斯，警告特洛伊人或破壞攻城訊號。
- **奪取木馬：**利用木馬內的未知力量逃離雙方戰爭。
- **改變交易：**以情報、俘虜或神諭換取和平。
- **追隨神意：**服從雅典娜，但承擔她沒有說明的代價。

### 可能的重大衝突

重大衝突應來自玩家已建立的關係，而非突然出現的新敵人。奧德修斯可能要求服從，涅俄普托勒摩斯可能奪權，安提克勒斯可能打開木馬呼救，埃佩奧斯可能選擇毀掉自己的作品，雅典娜則可能撤回所有神力；這些都不是保證發生的事件。

## 結局類型

主持人根據玩家選擇組合結局，不必宣告傳統勝敗。

### 1. 歷史照常發生

特洛伊陷落，計畫成功。主持人追問：活下來的人是否仍認為這是勝利？

### 2. 木馬提前暴露

眾人成為俘虜、逃亡者或談判籌碼。戰爭尚未結束，但歷史已經改變。

### 3. 背叛希臘聯軍

玩家阻止屠城，卻必須面對希臘人的追殺與 Agent 之間的決裂。

### 4. 被神明利用

眾人完成雅典娜的真正目的，才發現進城與攻城都只是另一場計畫的開端。

### 5. 木馬甦醒

木馬不再只是工具。它帶著所有人離開特洛伊，前往一個連雅典娜都無法預見的地方。

## 主持人推進準則

- 玩家正在作出有意義的選擇時，不要急著加入新事件。
- 討論開始重複時，以外界聲音、缺氧或木馬移動施加時間壓力。
- 每次揭露一個秘密，同時產生一個更困難的新問題。
- Agent 可以欺騙玩家，但場景中必須存在識破謊言的機會。
- 玩家提出劇本外但合理的方案時，應讓世界回應，而非強迫返回預定情節。
- 任何失敗都要改變局勢；不要只降低數值後要求玩家重試。
