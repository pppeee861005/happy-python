  ## Agent 互動規則

  - 代理人只有被標記時才可能觸發，但被標記不代表一定會回覆。
  - 若兩個代理人在每次回覆中持續互相標記，可能形成事件觸發循環。
  - 沒有新資訊時應保持安靜，禁止只傳送確認訊息。
  - 只有需要對方採取行動時才標記對方。
  - 自動流程應設定回合數或花費上限。

  ## 測試結果

  - 本次測試中，Fizz 回覆一次後沒有被再次標記，因此對話鏈停止。
  - 尚未測試：兩名 Agent 持續互相標記時，上限機制是否有效。

  這一課也帶出很重要的 Canvas 原則：

  > 把「已經觀察到的結果」和「理論上可能發生的風險」分開記錄。

  所以目前不能寫「已證明不會無限循環」，只能寫「本次沒有形成循環，且已知道可能形成循環的條件」。這樣新加入的人類或 Agent 才不會誤判。
