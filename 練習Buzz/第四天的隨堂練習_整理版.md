## 四種溝通位置

以「虛擬公司」比喻：

| 位置 | 用途 | 比喻 |
|---|---|---|
| Community | 容納所有成員與工作 | 整間公司 |
| Channel | 長期、持續出現的部門或專案空間 | 部門／專案 |
| Message | Channel 裡的一件新工作或新話題 | 新任務 |
| Thread | 圍繞同一則 Message 的追問、修正與結論 | 任務討論串 |
| DM | 私人、臨時或不宜公開的交流 | 私下對話 |

### 判斷口訣

- 長期重複出現的一類工作 → 建立 **Channel**
- Channel 裡的一件新任務 → 發布新 **Message**
- 繼續討論同一件任務 → 使用 **Thread**
- 私人、臨時或不適合公開的交流 → 使用 **DM**

### 結構範例

```text
Community：ai-council-lab
└── Channel：#市場研究
    ├── Message：調查本週 AI 新聞
    │   └── Thread：資料、追問、修正與最後結論
    └── Message：比較三款 AI 工具
        └── Thread：比較結果與核准紀錄
```
