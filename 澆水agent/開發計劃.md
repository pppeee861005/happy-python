# 澆水 Agent 開發計劃

## 📋 項目概述

**目標**：基於土壤濕度 + 6 小時天氣預報，使用 LLM 智能決策是否澆水

**技術棧**：
- Google GenAI SDK (Gemini)
- Python 3.10+
- 無需 LangGraph（簡化設計）

---

## 🏗️ 項目結構

```
澆水agent/
├── 開發計劃.md                    # 本檔案
├── main.py                        # 程式入口
├── prompts.py                     # LLM Prompt 模板
├── data_generator.py              # 模擬數據生成
├── water_agent.py                 # 核心決策邏輯

```

## 📝 模塊設計

### 1️⃣ `data_generator.py` - 模擬數據生成

**功能**：生成模擬的土壤濕度和天氣預報

| 函數 | 輸出 | 備註 |
|------|------|------|
| `get_mock_humidity()` | `float (0-100)` | 土壤濕度百分比 |
| `get_mock_weather_6h()` | `dict` | 6小時天氣預報 |

**weather_6h 數據結構**：
```python
{
    "precipitation_prob": float,  # 降雨機率 (%)
    "temperature": float,         # 溫度 (°C)
    "humidity": float,            # 空氣濕度 (%)
    "wind_speed": float           # 風速 (km/h)
}
```

### 2️⃣ `prompts.py` - LLM 提示詞

**設計原則**：
- SYSTEM_PROMPT：定義澆水決策原則
- USER_PROMPT：格式化用戶輸入

**輸出格式（JSON）**：
```json
{
    "decision": "澆水" | "不澆水",
    "reasoning": "詳細推理過程"
}
```

### 3️⃣ `water_agent.py` - 核心決策邏輯

**主要函數**：
- `WaterAgent` 類
  - `__init__(api_key, model_name)` - 初始化 GenAI 客戶端
  - `decide(humidity, weather_6h)` - 執行決策

**流程**：
1. 接收 humidity 和 weather_6h
2. 組裝 LLM 提示詞
3. 呼叫 Google Gemini API
4. 解析輸出（JSON）
5. 返回決策和推理過程

### 4️⃣ `main.py` - 程式入口

**流程**：
1. 載入環境變數 (.env)
2. 初始化 WaterAgent
3. 生成模擬數據
4. 執行決策
5. 格式化輸出

**輸出範例**：
```
🌱 澆水決策系統
━━━━━━━━━━━━━━━━━━━━━━━
📊 當前狀況
  • 土壤濕度：35.2%
  • 降雨機率：20.0%
  • 溫度：28.5°C
  • 空氣濕度：65.0%
  • 風速：5.3 km/h

🤖 LLM 決策
  決策：澆水

  推理過程：
  土壤濕度 35% 處於中等偏低水平，加上高溫 28.5°C 會加速
  土壤蒸散。雖然降雨機率只有 20%，不足以依賴天氣補水，
  因此建議立即澆水。

━━━━━━━━━━━━━━━━━━━━━━━
```

## 🎯 關鍵決策點

| 項目 | 決定 | 理由 |
|------|------|------|
| LLM 模型 | Gemini 3.5 Flash | 快速、成本低 |
| 數據格式 | 模擬 (隨機值) | 先驗證邏輯，後續易換成真實數據 |
| 決策方式 | 純 LLM 推理 | Agent-first，無硬編碼規則 |
| 輸出格式 | JSON | 易於解析和後續處理 |
| 執行時機 | 啟動程式時執行 | 後續改成定時 6 點早上 |
