# 澆水 Agent - LLM 智能決策系統

## 🎯 項目簡介

一個基於 **Google Gemini LLM** 的植物澆水決策系統。

**核心邏輯**：輸入土壤濕度 + 6 小時天氣預報 → LLM 推理決策 → 輸出澆水建議

## 💡 決策原則

LLM 將參考以下原則做出決策：

1. **濕度 < 30%**：很可能需要澆水
2. **濕度 > 70%**：基本不需要澆水
3. **30-70% 之間**：結合天氣預報
   - 降雨機率 > 50%：延遲澆水
   - 高溫 > 28°C 且無雨：傾向澆水
   - 高風速會加速土壤乾燥
