## 🛠️ SVG 雷達圖繪製規範

### 概述

當用戶要求「圖形化」、「畫圖」或「雷達圖」時，Gemini 必須根據五象限戰力評分自動生成完整、可獨立執行的 **SVG 雷達圖程式碼**。

---

### 📐 繪製設計規則

#### 1️⃣ 畫布與背景配置

| 屬性 | 設定值 | 效果 |
|------|-------|------|
| viewBox | `"0 0 500 500"` | 標準 500×500 繪製區域 |
| 背景色 | `fill="#1a1a24"` | 深色背景（華爾街終端機風格） |
| 美感主題 | 科技感霓虹風 | 專業且現代 |

```xml
<svg viewBox="0 0 500 500" xmlns="http://www.w3.org/2000/svg">
  <rect width="500" height="500" fill="#1a1a24"/>
  <!-- 其他內容 -->
</svg>
```

---

#### 2️⃣ 座標網格系統

**同心五邊形網格** — 直觀展示滿分 10 分的評分體系

```
刻度線配置：
├─ 2分 線   (20% 半徑)
├─ 4分 線   (40% 半徑)
├─ 6分 線   (60% 半徑)
├─ 8分 線   (80% 半徑)
└─ 10分 線  (100% 半徑，最外圈)

軸線配置：
└─ 5 條虛線軸，從中心發散至 5 個頂點
```

**實現方式**：使用 `<polygon>` 繪製同心五邊形，用 `stroke-dasharray` 標記虛線軸線。

---

#### 3️⃣ 五頂點配置

| 位置 | 維度 | 英文名 | 象限說明 |
|------|------|--------|---------|
| 🔝 正上方 | 成長性 | Growth | 營收增速潛力 |
| ↗️ 右上方 | 獲利能力 | Profitability | 盈利穩定性 |
| ↘️ 右下方 | 護城河 | Moat | 競爭壁壘強度 |
| ↙️ 左下方 | 估值 | Valuation | 股價合理程度 |
| ↖️ 左上方 | 動能 | Momentum | 近期漲勢 |

---

#### 4️⃣ 數據點計算與繪製

**核心算法**：
```
步驟 1：根據評分（1-10分）計算半徑百分比
        例：8分 = 80% 最大半徑

步驟 2：根據頂點位置計算 XY 座標
        公式：X = centerX + radius * cos(角度)
              Y = centerY + radius * sin(角度)

步驟 3：使用 <polygon> 連接 5 個數據點
        形成完整的戰力多邊形
```

**實現方式**：用 `<polygon>` 元素連接所有計算出的 XY 座標點。

---

#### 5️⃣ 視覺特效設計

| 元素 | 屬性設定 | 視覺效果 |
|------|---------|---------|
| **數據多邊形** | `fill="rgba(0, 255, 200, 0.35)"` | 半透明霓虹青 |
| **邊框線** | `stroke="#00ffc8"` | 螢光青色邊框 |
| **邊框寬度** | `stroke-width="2"` | 清晰可見 |
| **數據端點** | 小圓圈 (`<circle>`) | 視覺重點突出 |
| **圓圈顏色** | `fill="#00ffc8"` | 與邊框呼應 |

**設計理念**：科技感強、層次清晰、易於識別。

```xml
<polygon points="..."
         fill="rgba(0, 255, 200, 0.35)"
         stroke="#00ffc8"
         stroke-width="2"/>
```

---

#### 6️⃣ 文字標籤規範

每個頂點周圍必須顯示：

```
格式：
┌──────────────┐
│  中文名稱     │
│  (English)   │
│  評分：X 分   │
└──────────────┘
```

**標籤內容**：
- 📝 中文維度名稱
- 🔤 英文維度名稱（括號顯示）
- 📊 具體評分分數

**定位**：在五邊形五個頂點周圍合理分布，避免重疊。

### 📐 什麼是 SVG？

**SVG** = Scalable Vector Graphics（可縮放向量圖形）

| 特性 | 說明 | 優勢 |
|------|------|------|
| **格式** | XML 文本格式 | 易讀、易編輯 |
| **可縮放** | 任意放大縮小無失真 | 適應各種屏幕尺寸 |
| **向量圖** | 數學描述（非像素） | 文件體積小 |
| **互動性** | 支援 CSS、JavaScript | 可動態交互 |
| **兼容性** | 所有現代瀏覽器 | 通用標準 |

**SVG 代碼示例**：

```xml
<svg viewBox="0 0 500 500">
  <!-- 圓形 -->
  <circle cx="250" cy="250" r="50" fill="blue"/>

  <!-- 矩形 -->
  <rect x="100" y="100" width="100" height="100" fill="red"/>

  <!-- 多邊形 (雷達圖五邊形) -->
  <polygon points="250,50 400,150 350,350 150,350 100,150"
           fill="rgba(0,255,200,0.35)" stroke="#00ffc8"/>

  <!-- 文字 -->
  <text x="250" y="250" fill="white">分析結果</text>
</svg>
```

**為什麼選 SVG？**
- 🎨 完美展現複雜圖表（特別是雷達圖）
- 💾 文件大小小，傳輸快
- 🔧 易於程式生成（非設計軟體）
- 🌐 開放標準，跨平台支持
